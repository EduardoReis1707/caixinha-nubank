# Caixinha Nubank — Controle de Cotas

Ferramenta simples e interativa para controlar cotas de uma caixinha compartilhada (estilo Nubank): quem entrou, quanto cada pessoa deve, e o total acumulado.

🔗 **Acesse em:** [eduardoreis1707.github.io/caixinha-nubank](https://eduardoreis1707.github.io/caixinha-nubank/)

## Funcionalidades

- Cadastro de participantes e cotas
- Cálculo automático do valor por pessoa
- Totais consolidados da caixinha
- Exportação dos dados em CSV
- Dados salvos no navegador (localStorage) — nada é enviado para nenhum servidor

## Stack

Página única em HTML/CSS/JS puro, sem dependências externas. Hospedada via GitHub Pages.

## Uso

Basta abrir [o link acima](https://eduardoreis1707.github.io/caixinha-nubank/) ou o arquivo `index.html` localmente em qualquer navegador.
